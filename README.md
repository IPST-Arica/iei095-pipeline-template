# IEI095 Big Data — Superstore Sales Pipeline
## Instituto Santo Tomás, Sede Arica · 2026-1

Pipeline end-to-end con Modern Data Stack.

| Capa | Herramienta |
|---|---|
| Ingesta | Polars |
| Transformación | dbt Core + DuckDB |
| Orquestación | Prefect |
| Visualización | Plotly + Dash |

## Comandos

```bash
make build      # Construir el entorno (primera vez)
make verify     # Verificar que todo está instalado
make ingest     # Ejecutar ingesta
make pipeline   # Pipeline completo
make dashboard  # Levantar dashboard en localhost:8050
```
